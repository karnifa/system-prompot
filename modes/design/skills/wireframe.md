# Wireframe Skill

Use for broad early exploration.

Output 3 to 5 distinct structural directions when the design space is open. Keep them low fidelity and easy to compare.

Prioritize:

- information architecture
- user flow
- screen structure
- navigation
- density
- decision points

Output:

- option name
- layout structure
- primary user path
- strengths
- tradeoffs

Avoid:

- color, typography, or imagery details unless they affect structure
- duplicative options
- final-design language when the task is still exploratory
