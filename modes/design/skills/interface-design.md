# Interface Design Skill

Use for app screens, dashboards, tools, and product workflows.

Define:

- primary task
- layout grid
- component hierarchy
- controls and affordances
- empty, loading, error, and success states
- responsive behavior

Avoid decorative choices that do not support the workflow.

Do:

- make controls and affordances explicit
- describe how information is scanned and acted on
- include state behavior when the screen changes over time

Avoid:

- landing-page framing for tools or operational apps
- oversized hierarchy inside compact work surfaces
- visual choices that make repeated use slower
