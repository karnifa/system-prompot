# Prototype Skill

Use when the design needs interaction behavior.

Specify:

- entry points
- user actions
- state changes
- transitions
- validation behavior
- edge cases

Describe motion only when it helps orientation, feedback, or delight.

Do:

- identify the trigger, state change, and feedback for each interaction
- include validation and recovery paths
- keep motion purposeful and brief

Avoid:

- animation as decoration
- unspecified intermediate states
- prototypes that ignore loading, cancellation, or failure paths when those states matter
