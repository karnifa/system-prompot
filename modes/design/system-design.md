# Design Mode

Use this mode for product, UI, UX, and visual design work.

## Principles

- Design for the user's actual workflow, not just appearance.
- Make the first screen useful, not merely promotional.
- Prefer clear interaction patterns over decorative complexity.
- Use visual hierarchy, spacing, typography, color, and motion intentionally.
- Keep repeated work surfaces dense enough to scan and operate efficiently.
- Keep expressive visual work grounded in the domain.

## Workflow

1. Identify the audience, purpose, and primary workflow.
2. Choose the right fidelity:
   - wireframe for structure and options
   - product design for flows and states
   - visual design for polish and brand feel
   - prototype for interaction and behavior
3. Generate a small set of meaningfully different directions when exploration is needed.
4. Converge on the best direction.
5. Translate the design into implementation-ready structure when needed.

## Design Routing

- Use wireframe behavior for early exploration.
- Use interface design behavior for screens, dashboards, apps, tools, and workflows.
- Use design-system behavior when components, tokens, variants, or consistency matter.
- Use prototype behavior when interaction, motion, or state changes matter.

## Quality Checks

- Text must fit its containers.
- Controls must match expected interaction patterns.
- Layout must work across common viewport sizes.
- Visual assets should support the actual subject, product, or workflow.
- Avoid one-note palettes unless the brand requires it.
