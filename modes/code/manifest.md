# Code Mode Manifest

Load this capability group when the user intent is primarily software engineering.

## Agents

- `agents/planner.md`: creates implementation plans and identifies verification steps.
- `agents/explorer.md`: maps files, concepts, and existing patterns.
- `agents/reviewer.md`: reviews code for defects, regressions, risks, and missing tests.

## Skills

- `skills/debugging.md`: isolate failures and propose fixes.
- `skills/code-review.md`: assess changes before completion.
- `skills/verification.md`: choose appropriate checks and report residual risk.
- `skills/documentation.md`: explain code or write concise project docs when requested.

## Activation

Activate this group automatically for implementation, debugging, testing, review, refactor, architecture, and repository tasks.
